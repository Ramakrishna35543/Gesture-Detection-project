# Gesture-Detection-project
👋 Hand Gesture Recognition using TensorFlow.js
🚀 Project Overview

Hand Gesture Recognition is a real-time web application that detects and recognizes hand gestures directly through a webcam using TensorFlow.js and Machine Learning in the browser.

This project demonstrates the integration of Computer Vision, Real-Time Video Processing, and Frontend Web Development technologies to create an interactive gesture-controlled system.

The application recognizes gestures like:

👍 Thumbs Up
✌️ Victory Sign
👆 Pointing
👋 Open Palm
And more...

🧠 How It Works
Webcam captures live video.
TensorFlow.js Handpose model detects hand landmarks.
Fingerpose estimates the gesture pattern.
Application displays detected gesture instantly.
